# Groundskeeper beta

Beta builds of [Groundskeeper](https://github.com/rsjsoftwareltd/groundskeeper): newer than the weekly release, for
trying new features before they reach everyone. Each beta is tested by RSJ Software but may still have rough edges.

**To be offered betas:** in Groundskeeper, Settings -> Updates -> Update channel -> **Beta**. You are also offered every
weekly release as it comes out. Tick **Allow automatic updates** there too if you want them installed without asking.
Switching back to **Release** never installs an older version.

**To install one by hand:** download `GroundskeeperSetup.exe` from the newest release here and run it over your existing
install. Each release lists the installer's SHA-256 checksum.

This repository holds releases only. For everything else, use the main repository:
- [Documentation (wiki)](https://github.com/rsjsoftwareltd/groundskeeper/wiki)
- [Questions, feedback and bug reports (Discussions)](https://github.com/rsjsoftwareltd/groundskeeper/discussions)
